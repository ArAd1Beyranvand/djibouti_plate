# djibouti_plate

Djibouti's licence plates for plate_core. Includes themes, alphabets and an advisory validator.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/djibouti/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/djibouti';

const spec = country.specs.get('dj.standard');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `dj.standard`

## Themes

- `DjiboutiThemes.current`
- `DjiboutiThemes.legacy`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`DjiboutiValidator`).
