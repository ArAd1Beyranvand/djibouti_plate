## Quick start

### Install (Python)

Copy `python/plates/countries/djibouti/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.djibouti.data import SPECS, THEMES

spec = SPECS["dj.standard"]
theme = THEMES["DjiboutiThemes.current"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `dj.standard`

## Themes

- `DjiboutiThemes.current`
- `DjiboutiThemes.legacy`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `DjiboutiValidator` to classes.
